# Google Search Console

Use this property after the GitHub Pages website is live:

- Website: https://arafid.github.io/
- Sitemap: https://arafid.github.io/sitemap.xml

## Verify ownership

1. Sign in at https://search.google.com/search-console/ with the Google account that should manage the portfolio.
2. Add a **URL prefix** property for `https://arafid.github.io/`.
3. Choose **HTML tag** verification and copy Google's complete `google-site-verification` meta tag.
4. Provide the tag in the portfolio conversation so it can be added inside the homepage `<head>`. No placeholder verification token is installed.
5. After the change is published, return to Search Console and click **Verify**. Keep the verification tag in the site afterward.

## Request discovery

1. In **Sitemaps**, submit `sitemap.xml`.
2. In **URL inspection**, inspect the homepage and request indexing if offered.
3. Monitor **Page indexing** for processing and exclusions.

Verification, sitemap submission, and indexing requests have not been completed by preparing this repository. Google determines whether and when to index pages and how they rank.
